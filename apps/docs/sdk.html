@KURABASE/JS

An independent, fetch-native TypeScript client

The SDK is not a wrapper around supabase-js. It speaks Kurabase’s REST contract directly while retaining a familiar query-builder shape.

Create a client

import { createClient } from '@kurabase/js'

const db = createClient('http://127.0.0.1:8787', 'publishable-key')

// Signing happens in your wallet or identity-provider integration, never in the SDK.
const exchanged = await db.auth.exchangeSession(preSignedEnvelope)
// `db` now uses exchanged.data.access_token for later requests.

Query and mutate

const { data, error, count } = await db
  .from('posts')
  .select('id,title,author:profiles!inner(name)', { count: 'exact' })
  .eq('published', true)
  .order('id', { ascending: false })
  .range(0, 24)

await db.from('posts').insert({ id: 1, title: 'Hello' })
await db.from('posts').upsert({ id: 1, title: 'Hello' }, { onConflict: 'id' }).select()

Builders are immutable and thenable. Mutations return no rows by default; chain .select() to request a representation. The response shape is { data, error, count, status, statusText }.

Call SQL-language functions

const answer = await db.rpc('add_one', { n: 41 })
const posts = await db.rpc('get_posts', { minimum: 1 }).select('id,title')

RPC supports scalar, SETOF/table, and atomic mutating SQL-language functions. Procedural functions and unsupported SQL return explicit errors.

Admin helpers

const admin = createClient(url, process.env.KURABASE_SECRET_KEY!)
const instance = await admin.admin.instance()
const catalog = await admin.admin.catalog()
const sql = await admin.admin.sql('select * from posts')
await admin.admin.migrations.apply({ version: '202609090001', sql: 'create table ...' })

Instance and catalog introspection work with project access. SQL and migrations require a secret key in a trusted server process. The browser Console keeps a supplied secret and bearer session only in memory.

Stable errors

Gateway errors retain their stable code, message, details, and hint. Client cardinality errors use KURA_CARDINALITY; transport failures use KURA_FETCH.
