RELATIONAL DATA · CANONICAL CHAIN STATE

Build applications with SQL-shaped data and explicit on-chain authority.

Kurabase is an early developer platform that presents a Supabase-style REST surface over a chain-backed relational state model. It is built for demos and exploration, not production custody or confidentiality.

Run a local instanceRead the SDK guide →

01

Familiar data access

Use a small independent TypeScript SDK, standard REST routes, filters, mutations, relation projections, and SQL-language RPC.

02

Deterministic writes

Writes are planned, authorized, and committed to canonical chain state. Gateway projections are rebuildable read models.

03

Visible trade-offs

Public-chain state is not secret. Signed sessions identify callers, while the gateway remains a trusted executor.

HONEST STATUS

Hackathon implementation in progress

Working paths include versioned migrations, CRUD, common filters, RLS, catalog/admin endpoints, SQL-language RPC, the independent TypeScript SDK, and a local Anvil workflow. Scalar, SETOF/table, and atomic mutating SQL functions are tested. Kurabase does not claim PostgreSQL wire compatibility, full SQL:2023 coverage, production high availability, private data, or general-purpose smart-contract security.
